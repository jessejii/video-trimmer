# 视频处理工具集 (Video Processing Tools)

这是一个基于 Python 和 FFmpeg 开发的高效视频处理工具箱。它专注于提供快速的视频**裁剪**、**合并**和**格式转换**功能，并特别针对 **AMD 显卡**进行了硬件加速优化，旨在解决视频编辑中常见的重复性工作。

## ⚠️ 核心配置与硬件加速说明 (重要)

本项目在视频转码和合并时，深度集成了硬件加速功能。请务必阅读以下说明以确保最佳性能：

### 1. AMD GPU 硬件加速 (`h264_amf`)
*   **首选方案**：默认支持使用 `h264_amf` 编码器调用 AMD 显卡进行硬件编码。
*   **优势**：速度远快于 CPU 编码，且能有效防止视频合并后出现的音画不同步或卡顿问题。
*   **常见问题与解决方案**：
    *   如果您使用的是较旧的显卡，或者运行报错（例如找不到编码器），通常是因为系统或 Conda 环境中的 `ffmpeg` 版本过旧或不支持 AMF。
    *   **解决方案**：需要手动替换 `ffmpeg` 可执行文件。
    *   **下载地址**：[https://github.com/BtbN/FFmpeg-Builds/releases](https://github.com/BtbN/FFmpeg-Builds/releases) (建议下载 `ffmpeg-master-latest-win64-gpl.zip`)
    *   **替换步骤**：
        1.  解压下载的压缩包，找到 `bin` 文件夹下的 `ffmpeg.exe`。
        2.  找到您 Python 环境下的 `ffmpeg.exe` 位置。如果您使用的是 **Conda** 环境，通常位于 `envs\您的环境名\Library\bin\ffmpeg.exe` 或 `envs\您的环境名\bin\ffmpeg.exe`。
        3.  使用新下载的 `ffmpeg.exe` 覆盖旧文件。

### 2. CPU 编码备用方案 (`libx264`)
*   **备用方案**：如果您的设备没有 AMD 显卡，或者硬件编码出现兼容性问题，工具会自动或允许手动选择使用 `libx264` 进行 CPU 编码。
*   **特点**：兼容性最好，生成的画质非常稳定，但处理速度相对较慢，占用 CPU 资源较高。

## 🛠️ 功能模块详解

本项目包含多个独立的 Python 脚本，对应不同的处理场景。大多数功能配有 `.bat` 批处理文件，支持**直接拖拽**文件使用。

### 1. 视频合并 (`merge_videos.py`)
将文件夹内的多个视频按名称排序后合并为一个文件。
*   **支持模式**：
    *   **模式 1 (快速合并)**: 仅进行流复制 (`-c copy`)，速度极快，但对源文件一致性要求高。
    *   **模式 2 (CPU 转换)**: 使用 `libx264` 统一重编码后合并。
    *   **模式 3 (快速转换)**: 先统一容器封装再合并。
    *   **模式 4 (GPU 直接合并)**: **(强烈推荐)** 使用 `h264_amf` 直接重编码合并。能一次性解决格式不统一导致的卡顿问题，效率极高。
*   **使用方法**: 运行脚本后输入文件夹路径，根据提示选择模式。

### 2. 视频裁剪 (Trimming)
*   **边缘裁剪 (`trim_edges.py`)**:
    *   功能：快速切除视频的“开头 X 秒”和“结尾 Y 秒”。
    *   特点：默认使用流复制模式，无损且秒级完成。
    *   支持：单个文件或批量文件夹处理。
    *   *命令示例*: `python trim_edges.py input.mp4 00:01:00 00:02:00` (切除前1分钟，保留到32分钟)

*   **批量时长裁剪 (`batch_trim_edges.py`)**:
    *   功能：针对文件夹内所有视频，统一“切掉开头 X 秒”和“切掉结尾 Y 秒”。
    *   适用场景：批量处理具有相同片头片尾的剧集或录播。

*   **多段智能删除 (`remove_segments.py`)**:
    *   功能：指定一个或多个需要删除的时间段，脚本会自动保留其余部分并合并。
    *   *示例*: `1:00-1:30,5:00-6:00` (删除第1分到1分半、第5分到6分的内容)。

### 3. 格式转换 (`convert_to_mp4.py`)
将任意视频格式转换为标准的 MP4 文件。
*   **极速模式**: 仅更换容器 (`-c copy`)，不重编码。
*   **重编码模式**: 可选 CPU (`libx264`) 或 GPU (`h264_amf`) 进行重新编码，修复编码错误或压缩体积。

### 4. 字幕工具箱
*   **SRT 转 ASS (`srt_to_ass.py`)**:
    *   将 `.srt` 字幕转换为样式更丰富的 `.ass` 格式。默认样式已针对中文字体优化（文泉驿正黑，大字号，阴影），适合视频压制。
*   **字幕重命名 (`rename_srt_to_txt.bat`)**:
    *   简单的批处理工具，用于批量修改字幕文件后缀，方便文本编辑。

### 5. 视频时间线重新计算器 (`video_timeline_calculator.html`)
一个基于 Web 的交互式工具，用于处理视频时间线中的广告段删除和时间重新计算。
*   **核心功能**：
    *   **智能广告检测**：自动识别时间线中标记为 `[广告]` 的内容段落
    *   **时间线重新计算**：删除广告段后，自动重新计算后续所有时间点
    *   **可视化计算过程**：详细显示每个广告段的时长和累计减少时间
    *   **一键复制功能**：支持复制处理后的时间线和计算方法说明
*   **使用场景**：
    *   处理录播视频的时间线，去除广告段后重新生成章节标记
    *   为视频剪辑提供准确的时间参考点
    *   批量处理带有广告的视频内容时间线
*   **输入格式示例**：
    ```
    00:00 开场介绍
    02:10 主要内容开始
    01:33:00 [广告] 广告内容
    01:35:00 内容继续
    ```
*   **使用方法**：直接在浏览器中打开 `video_timeline_calculator.html` 文件即可使用，无需额外安装。

## 📦 环境依赖

*   **Python 3.8+**
*   **FFmpeg**: 必须配置在系统环境变量 PATH 中，或直接替换环境内的 ffmpeg 可执行文件（参考上文“硬件加速说明”）。

## 🚀 快速开始

1.  **安装依赖**:
    ```bash
    pip install -r requirements.txt
    # (注：主要依赖标准库和系统 ffmpeg)
    ```
2.  **运行方式**:
    *   **方式 A (推荐)**: 找到对应的 `.bat` 文件 (如 `merge_videos.bat`)，直接双击运行，或将视频文件/文件夹**拖拽**到 `.bat` 图标上。
    *   **方式 B (命令行)**:
    ```bash
    python merge_videos.py
    ```
